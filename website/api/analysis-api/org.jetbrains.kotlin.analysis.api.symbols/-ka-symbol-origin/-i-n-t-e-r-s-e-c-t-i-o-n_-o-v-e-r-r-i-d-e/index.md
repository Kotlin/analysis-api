# INTERSECTION_OVERRIDE

<div markdown>

<div class="highlight"><pre><code class="md-code__content"><span markdown><a href="index.html">INTERSECTION_OVERRIDE</a>

</span></code></pre></div>A declaration from a synthetic callable generated by the Kotlin compiler for callable intersections.

#### Example
```
interface A { fun foo() }
interface B { fun foo() }

interface C : A, B
```

A synthetic function `C.foo` will be created from the intersection of `A.foo` and `B.foo` with an [`INTERSECTION_OVERRIDE`](index.md) origin.
