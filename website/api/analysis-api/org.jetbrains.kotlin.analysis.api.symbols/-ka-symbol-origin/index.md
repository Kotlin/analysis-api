# KaSymbolOrigin

<div markdown>

<div class="highlight"><pre><code class="md-code__content"><span markdown><span class="kd">enum class </span><a href="index.html">KaSymbolOrigin</a> : <a href="https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-enum/index.html">Enum</a><span class="o"><</span><a href="index.html">KaSymbolOrigin</a><span class="o">> </span>
</span></code></pre></div>[`KaSymbolOrigin`](index.md) describes the kind of data source (sources, libraries, etc.) or generation (SAM constructors, compiler plugins, etc.) the symbol originates from.

In cases where the origin is a generated declaration (e.g. [`SAM_CONSTRUCTOR`](-s-a-m_-c-o-n-s-t-r-u-c-t-o-r/index.md), [`DELEGATED`](-d-e-l-e-g-a-t-e-d/index.md), [`JAVA_SYNTHETIC_PROPERTY`](-j-a-v-a_-s-y-n-t-h-e-t-i-c_-p-r-o-p-e-r-t-y/index.md)), not only the generated declaration itself will have this origin, but all declarations contained in it as well. For example, while [`KaSamConstructorSymbol`](../-ka-sam-constructor-symbol/index.md) has a [`SAM_CONSTRUCTOR`](-s-a-m_-c-o-n-s-t-r-u-c-t-o-r/index.md) origin, its value parameters also share the same [`SAM_CONSTRUCTOR`](-s-a-m_-c-o-n-s-t-r-u-c-t-o-r/index.md) origin.


</div>
