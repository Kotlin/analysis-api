# DELEGATED

<div markdown>

<div class="highlight"><pre><code class="md-code__content"><span markdown><a href="index.html">DELEGATED</a>

</span></code></pre></div>A declaration from a member generated by the compiler for interface delegation. This occurs when a class delegates the implementation of an interface to another object.

#### Example
```
interface MyInterface {
    fun perform()
}

class MyClass(private val delegate: MyInterface) : MyInterface by delegate
```

The compiler generates a member function `perform()` in `MyClass` that calls the `perform()` function from `delegate`.
