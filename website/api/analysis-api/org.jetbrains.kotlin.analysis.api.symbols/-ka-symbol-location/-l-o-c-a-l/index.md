# LOCAL

<div markdown>

<div class="highlight"><pre><code class="md-code__content"><span markdown><a href="index.html">LOCAL</a>

</span></code></pre></div>Symbols which are defined directly inside a body.

[`LOCAL`](index.md) is not propagated to the members of local classes. So the member declaration of a local class has [`CLASS`](../-c-l-a-s-s/index.md) as its location and not [`LOCAL`](index.md).
