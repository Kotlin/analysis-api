# KaDeprecationLevel

<div markdown>

<div class="highlight"><pre><code class="md-code__content"><span markdown><span class="kd">class </span><a href="index.html">KaDeprecationLevel</a>
</span></code></pre></div>Deprecation severity levels, corresponding to [`DeprecationLevel`](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-deprecation-level/index.html) in the Kotlin standard library.

The levels form a progression from least to most restrictive: [`WARNING`](-companion/index.md#warning) produces a compiler warning, [`ERROR`](-companion/index.md#error) produces a compiler error, and [`HIDDEN`](-companion/index.md#hidden) makes the declaration invisible to new code.
