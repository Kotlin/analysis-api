# KaAnnotationValue

<div markdown>

<div class="highlight"><pre><code class="md-code__content"><span markdown><span class="kd">sealed </span><span class="kd">interface </span><a href="index.html">KaAnnotationValue</a> : <a href="../../org.jetbrains.kotlin.analysis.api.lifetime/-ka-lifetime-owner/index.html">KaLifetimeOwner</a>
</span></code></pre></div>[`KaAnnotationValue`](index.md) represents the [value](https://kotlinlang.org/spec/annotations.html#annotation-values) of an annotation argument.

Annotation values must be compile-time constants. They are restricted in their allowed types, which are:

 - Integers, [`Boolean`](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-boolean/index.html), and [`String`](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/index.html) ([`ConstantValue`](-constant-value/index.md))


 - Enum types ([`EnumEntryValue`](-enum-entry-value/index.md))


 - [`KClass`](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.reflect/-k-class/index.html) ([`ClassLiteralValue`](-class-literal-value/index.md))


 - Other annotation types ([`NestedAnnotationValue`](-nested-annotation-value/index.md))


 - Arrays of aforementioned types ([`ArrayValue`](-array-value/index.md))


#### Examples
```kotlin
@Foo1(5, true, "foo")                        // Constant values
@Foo2(Color.RED)                             // Enum entries
@Foo3(String::class)                         // `KClass` values
@Foo4(Foo2(Color.RED))                       // Nested annotation values
@Foo5([Color.RED, Color.GREEN, Color.BLUE])  // Arrays
```
