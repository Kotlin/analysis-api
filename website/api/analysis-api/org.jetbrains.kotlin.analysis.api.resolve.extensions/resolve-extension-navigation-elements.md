<div markdown>

A list of PsiElements which are used as navigation targets in place of this [`KtElement`](../../psi-api/org.jetbrains.kotlin.psi/-kt-element/index.md) provided by a [`KaResolveExtension`](-ka-resolve-extension/index.md).

These PsiElements will typically be the source item(s) that caused the given [`KtElement`](../../psi-api/org.jetbrains.kotlin.psi/-kt-element/index.md) to be generated by the [`KaResolveExtension`](-ka-resolve-extension/index.md). For example, for a [`KtElement`](../../psi-api/org.jetbrains.kotlin.psi/-kt-element/index.md) generated by a resource compiler, the navigation elements will typically be the PsiElements of the resource items in the corresponding resource file.
