<div markdown>

Renders the given [`KaType`](../../org.jetbrains.kotlin.analysis.api.types/-ka-type/index.md) into a string. The particular rendering strategy is defined by the [`renderer`](index.md#render).

[`position`](index.md#render) controls the way the given type is approximated using [`KaTypeRenderer.typeApproximator`](../../org.jetbrains.kotlin.analysis.api.renderer.types/-ka-type-renderer/index.md#typeapproximator).

Specifically, when [`KaRendererTypeApproximator.TO_DENOTABLE`](../../org.jetbrains.kotlin.analysis.api.renderer.declarations/-ka-renderer-type-approximator/-t-o_-d-e-n-o-t-a-b-l-e/index.md) is used, no approximation is performed for Variance.INVARIANT, a denotable subtype is rendered for Variance.IN_VARIANCE, and a denotable supertype is rendered for Variance.OUT_VARIANCE.


</div>
